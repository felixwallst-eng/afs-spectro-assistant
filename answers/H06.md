## Measurement concept

## First feasibility study

1. Obtain ex‑vivo tissue samples that mimic the expected in‑vivo state (e.g., fresh soft tissue).
2. Select a probe (ATR or Raman) compatible with the sample state and connect it with the intended fibre link.
3. Record spectra on the probe and on a reference benchtop spectrometer under identical conditions.
4. Build a classification model (e.g., PLS‑DA) using the probe data and validate against the reference measurements.
5. Compare model performance (accuracy, sensitivity) to the published study to assess feasibility.
