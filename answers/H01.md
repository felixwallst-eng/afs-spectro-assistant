## Measurement concept

An in‑line probe will be positioned at the tablet press feed frame to interrogate the powder blend directly; the probe will be linked to the spectrometer via a fiber optic cable whose type and length must be confirmed to support the chosen spectral range [S01 p.15; S01 p.5].

## Spectral range

Raman probe operates nominally over 400–1100 nm (e.g., 785 nm excitation) and NIR probes cover 780–2500 nm; the exact usable range depends on the fiber link and must be verified for the installed fiber [S01 Table 1 (p.6)].

## Risks, limitations and uncertainty

- Matrix change makes the existing calibration invalid; adding Raman does not preserve the old model [S01 p.10].
- If the installed fiber does not transmit the required wavelengths, the chosen method may be unusable.
- Uncharacterised optical variability of the powder could degrade signal quality.
- Unknown API concentration may be outside the detection capability of the tested methods.

## First feasibility study

1. Assemble a laboratory test rig with the Raman probe and a NIR diffuse‑reflection probe using the same powder blend as in the process.
2. Prepare reference samples spanning the expected API concentration range (to be defined) and acquire spectra with both probes.
3. Build preliminary calibration models for Raman and NIR data and evaluate prediction error against independent reference analysis (e.g., HPLC).
4. Simulate process optical variability (e.g., change bulk density, add air bubbles) and record the effect on spectral quality.
5. Compare laboratory results with the constraints of the installed fiber link to confirm that the required spectral range can be delivered.

## Decision basis

A go decision will be made if a calibration model built with the new powder blend meets the client’s required prediction accuracy and robustness to matrix variability, as demonstrated in the feasibility test; otherwise the method will be rejected.
