## Recommended methods

- **Raman – Raman probe.** Worth testing because Raman scattering works on powders, offers high chemical selectivity and uses the same probe geometry as the existing NIR setup [S01 Table 1 (p.6)].
- **Near‑IR – Diffuse reflection probe.** Worth testing as diffuse‑reflection NIR is proven for powder blends and matches the current in‑line configuration [S01 Table 1 (p.6)].
- **Near‑IR – Surface‑at‑a‑distance probe.** Worth testing if a non‑contact geometry is preferred; it also handles powders effectively [S01 Table 1 (p.6)].
- **Near‑IR – Integrating sphere (conditional).** Worth testing in the laboratory to obtain high‑quality reference spectra before moving to an inline probe; not suitable for direct in‑line installation [S01 Table 1 (p.6)].

## Measurement concept

An in‑process probe will be positioned at the tablet press feed frame to collect either Raman scattered light or diffuse‑reflection NIR from the moving powder stream; the probe is linked to a remote spectrometer via fibre optics, keeping the analyser away from vibration and dust [S01 p.15; S01 p.5].

## Spectral range

Raman probe operates in the visible to short‑wave NIR (≈400–1100 nm) with typical 785 nm excitation; NIR diffuse‑reflection probes cover 780–2500 nm. The exact usable range depends on the installed fibre type and length and must be verified for any mid‑IR option [S01 Table 1 (p.6)].

## Risks, limitations and uncertainty

- Matrix change makes the existing NIR calibration invalid (calibrations are matrix‑specific) [S01 p.10]
- Uncertain fibre transmission may limit the spectral range or introduce losses
- Optical variability (turbidity, bubbles) could degrade signal quality
- Unknown API concentration range may require higher sensitivity than the tested methods provide

## First feasibility study

1. 1. Install the Raman probe on the feed frame and connect it with the current fibre link; acquire Raman spectra of the new blend.
2. 2. Use the existing NIR diffuse‑reflection probe (or surface‑at‑a‑distance probe) to collect NIR spectra under identical process conditions.
3. 3. Collect independent reference concentrations (e.g., HPLC) for a set of samples covering the expected API range.
4. 4. Build preliminary calibration models for Raman and NIR data and evaluate prediction errors against the reference values.
5. 5. Compare the two techniques for signal quality, robustness to optical variability, and ability to meet the required detection change.

## Decision basis

A go decision will be made if a calibration model built from the new blend using Raman and/or NIR meets the client’s acceptable prediction error (as defined in the process monitoring specification). Failure to achieve the target error or inability to obtain reliable spectra due to fibre or optical variability will lead to a no‑go.
